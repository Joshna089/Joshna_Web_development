CSS Selectors

1. Element Selector :

Selects HTML elements by their tag (type).
Example: p { color: red; } targets all <p> elements.
- drawbag is applied to all elements of that type.

2. Class Selector :

Select elements with a specific class attribute.
Example: .my-class { font-size: 16px; } targets all elements with the class "my-class".
- drawbag is applied to all elements with a specific class.

3. Id Selector :

Select an element with a specific id attribute.
Example: #my-id { background-color: blue; } targets the element with the id "my-id".
- drawbag is applied to the element with a specific id.

4. Child Selector :

Select child elements of a specific parent element.
Example: div > p { color: red; } targets all <p> elements that are direct children of a <div> element.
- drawbag is applied to the child elements.

5. Descendant Selector :

Select elements that are descendants of a specific parent element.
Example: div p { color: red; } targets all <p> elements that are descendants of a <div> element.
- drawbag is applied to the child elements of the parent element.

6. Universal Selector :

Select all elements in the document.
Example: * { margin: 0; padding: 0; } targets all elements in the document.
- drawbag is applied to all elements.

7. Pseudo Selectors:

Select elements based on their state or position in the document.
Example: a:hover { color: red; } targets all <a> elements when they are being hovered over by the mouse.
(:hover, :first-child, :last-child, :nth-child(n), :not(selector), :checked, :disabled, :enabled, :focus, :active, :visited, :link)
- drawbag is applied to elements based on their state or position in the document.

8. Attribute Selector :

Select elements with a specific attribute or attribute value.
Example: input[type="text"] { border: 1px solid black; } targets all <input> elements with the type attribute set to "text".
- drawbag is applied to elements with specific attributes.
