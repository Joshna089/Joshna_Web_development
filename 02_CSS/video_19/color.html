Adding colors to html

Five ways to Add colors to Html using CSS.

  1. { color : red;}

    2. Named Color:Uses the predefined color names like red,blue,gold.

  2. color: rgb(255, 200, 232);

    3. RGB : Defines color using Red,Green, Blue value from ( 0 to 255 )

  3. color:rgba(154, 231, 11,0.925)

    4. Same as RGB but adds Alpha for transparency ( 0 to 1 ).

  4. color: #57863;

    5. Defines color using 6-digit hexa_decimal code for Red, Green, Blue.

  5. color:hsl( 252, 97%, 15% )

    6. Defines color using Hue, Saturation and Lightness percentages.
