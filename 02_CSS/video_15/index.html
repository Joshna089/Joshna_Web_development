CSS_3

The CSS is of three types: Inline, Internal and External.

  1. Inline CSS :

    2. Inline CSS is used to apply styles directly to an HTML element using the `<style>` attribute.

  2. Internal CSS :

    3. Internal CSS is used to apply styles to an entire HTML page including all the elements within it.

  3. External CSS :

    4. External CSS is used to apply styles to an entire HTML page by linking to an external CSS file using the `<link>` tag in the `<head>` section.
